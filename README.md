# AuraCard

Create stunning digital visiting cards instantly with a premium modern UI, live preview, QR sharing, themes, and easy customization.

## ✨ Features

* Premium responsive landing page
* Smart digital business card builder
* Live card preview while editing
* Upload profile photo
* Multiple premium themes
* Brand color picker
* Font style customization
* Card shape customization
* Shadow / glow effects
* Social media links support
* QR code generation
* Shareable public card link
* Auto save with Local Storage
* Demo card preview
* Mobile friendly design
* Smooth animations and glassmorphism UI

## 🎨 Themes Included

* Executive
* Minimal
* Royal
* Neon
* Ocean

## 🛠 Built With

* HTML5
* Tailwind CSS
* JavaScript
* Lucide Icons
* QRCode.js
* Google Fonts

## 🚀 How to Use

1. Open the website
2. Click **Create Card**
3. Fill your personal details
4. Upload profile image
5. Select theme and style
6. Add social links
7. Save your card
8. Share via link or QR code
